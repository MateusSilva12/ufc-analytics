Projeto completo de análise de dados dos lutadores da UFC utilizando **Web Scraping**, **Dashboard Interativo** e **Análise Estatística**.

## 📊 Sobre o Projeto

Este projeto coleta, processa e analisa dados de lutadores da UFC para extrair insights valiosos sobre performance, estilos de luta e records históricos.

### 🎯 Funcionalidades Principais

- **🔍 Web Scraping** - Coleta automática de dados de 4.447 lutadores
- **📈 Dashboard Interativo** - Visualização em tempo real com Streamlit
- **📊 Análise Estatística** - Insights sobre vitórias, derrotas e performance
- **👥 Sistema de Busca** - Encontre e compare qualquer lutador
- **⚔️ Comparações** - Análise lado a lado entre lutadores
